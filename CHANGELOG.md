## [0.6.5a1] — 2026-11-26 (Phase 6.5 Alpha: P0/P1 Hardening, Real NumPy/PyArrow & Universal Nox Package Bindings)

### Fixed & Hardened (Phase 6.5-A)
- **P0-1 Subinterpreter callbacks & async thread-state:** Replaced `PyGILState_Ensure()` in `noxpy_cb_invoke` and `noxpy_async_on_done` with `PyThreadState_New(interp)` / `PyEval_AcquireThread` / `PyThreadState_Clear` / `PyEval_ReleaseThread` / `PyThreadState_Delete` for subinterpreters (`owner_interp_id > 0`), plus deferred `Py_DECREF` queueing (`extref_drain_deferred`) so `noxpy_cb_release` never attaches from an unowned foreign/worker thread. Verified sync callbacks, exception round-trips, and `asyncio.run` inside dual `3.15` & `3.15t` `concurrent.interpreters` in [`tests/packaging/test_phase6_5_hardening.py`](tests/packaging/test_phase6_5_hardening.py).
- **P0-2 Async abandoned context retirement:** Added per-module `NoxPyRetiredCtx` list (`noxpy_module_retire_ctx` / `noxpy_module_drain_retired`) in [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) & [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) so async contexts orphaned on premature `loop.close()` are deterministically destroyed outside the worker thread.
- **P0-3 Atomic buffer `close()` & NumPy `writable_array` unpin:** Moved `active_pins > 0` check inside `data->lock` (`obj_close_checked_impl`) and updated [`python/noxpy/numpy_adapter.py`](python/noxpy/numpy_adapter.py) `writable_array` to revoke `write=False` and deterministically release `arr.base` `memoryview` on exit.
- **P1-1 Plain Python `list[float|int|bool]` fast C-pack path & P1-2 real `numpy`/`pyarrow` verification:** Added single-pass strict C packing to `NOX_HOST_VALUE_TYPED_ARRAY` inside `py_to_hv_rec` (eliminating the `~2.24 s` per-element value-tree bottleneck while preserving strict `TypeError`/`OverflowError` semantics) and added real `numpy` + `pyarrow` PyCapsule zero-copy tests in [`tests/packaging/test_phase6_5_hardening.py`](tests/packaging/test_phase6_5_hardening.py).

### Added (Phase 6.5-B — Universal Nox Package Bindings)
- Added [`python/noxpy/pkg_bridge.py`](python/noxpy/pkg_bridge.py) (`inspect_nox_package`, `generate_package_wrapper`), CLI commands `noxpy check --compatibility` and `noxpy init --from-nox-package` ([`python/noxpy/__main__.py`](python/noxpy/__main__.py)), aligned `[tool.noxpy].export` (`"explicit"` | `"public"`) validation in [`python/noxpy/config.py`](python/noxpy/config.py) & [`src/builder/config.nox`](src/builder/config.nox), [`tests/unit/test_pkg_bridge.py`](tests/unit/test_pkg_bridge.py), [`tests/packaging/test_phase6_5_universal_packages.py`](tests/packaging/test_phase6_5_universal_packages.py), [`UR-016`](UPSTREAM_REQUIREMENTS.md), and [`docs/evidence/phase6_5-2026-11-26.md`](docs/evidence/phase6_5-2026-11-26.md).

## [0.6.0a1] — 2026-11-26 (Phases 5 & 6 Alpha: Zero-Copy Buffers, NumPy, Atlas, Arrow, Noxen & Subinterpreters)

### Added (Phase 6 — Subinterpreters `UR-013`, Arrow, Noxen, Embedding Policy & Windows CI)
- **Subinterpreter isolation (`UR-013`):** Switched emitted modules (`src/codegen/emit_c.nox`, `python/noxpy/codegen.py`) to `Py_MOD_PER_INTERPRETER_GIL_SUPPORTED`; added `owner_interp_id` tracking and cross-interpreter rejection (`noxpy_module_lease_acquire`, `noxpy_obj_enter_call`, `noxpy_buf_extract_data`) plus `NOX_HOST_CAP_SUBINTERPRETERS` runtime verification in [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) and [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) (`python/noxpy/_native/` synced). Added `PyInterpreterState_Get`/`PyInterpreterState_GetID` and optional `NOXPY_MAX_GLIBC` Linux checks to [`python/noxpy/audit.py`](python/noxpy/audit.py).
- **Portable Win32/POSIX mutex layer:** Replaced POSIX-only `pthread_mutex_t` / `sched_yield` / `pthread_threadid_np` in [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) and [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) with portable `noxpy_mutex_t` / `noxpy_cpu_yield` (`CRITICAL_SECTION` / `SwitchToThread` / `GetCurrentThreadId` on `_WIN32`).
- **Arrow C Data & C Stream adapter:** Added [`python/noxpy/arrow_adapter.py`](python/noxpy/arrow_adapter.py), [`integrations/arrow/README.md`](integrations/arrow/README.md), [`tests/unit/test_arrow_adapter.py`](tests/unit/test_arrow_adapter.py), and [`ADR-0008`](docs/adr/0008-buffers-numpy-ownership.md) Addendum §5 providing zero-copy `__arrow_c_schema__` / `__arrow_c_array__` / `__arrow_c_stream__` PyCapsule interop over PEP 3118 buffers with pin enforcement, `offset` slicing, and `null_count == 0` checks.
- **Noxen validation example & gated embedding profile:** Added [`examples/noxen/`](examples/noxen/) (`ValidationError`, `is_valid_email`, `is_valid_date`, `is_valid_ipv4`, `UserValidator`) and [`src/runtime/embed.nox`](src/runtime/embed.nox) + [`tests/nox/embed_test.nox`](tests/nox/embed_test.nox) + [`ADR-0009`](docs/adr/0009-embedding-and-platform-matrix.md) documenting the deferred `cp315-embed` policy and P0 platform matrix.
- **Dual-mode subinterpreter E2E & CI expansion:** Verified independent concurrent subinterpreters (`concurrent.interpreters`), Arrow zero-copy pins over `F64Buffer`, and Noxen wheels on `CPython 3.15` & unforced `3.15t` in [`tests/packaging/test_phase6_arrow_noxen_subinterp.py`](tests/packaging/test_phase6_arrow_noxen_subinterp.py); added `windows-nox-toolchain-smoke` (`nox-lang v2.2.95` Windows x64 + `tests/nox` + `tests/unit`) to [`.github/workflows/ci.yml`](.github/workflows/ci.yml) and archived evidence in [`docs/evidence/phase6-2026-11-26.md`](docs/evidence/phase6-2026-11-26.md).

### Added (Phase 5 — `noxc v2.2.95`, Zero-Copy Buffers `UR-012`, NumPy Adapter & Atlas Benchmarks)
- Implemented zero-copy PEP 3118 `F64Buffer`/`I64Buffer`/`I32Buffer`/`U8Buffer` heap types (`Py_bf_getbuffer`, `Py_bf_releasebuffer`, exclusive `.writable()` proxy, `NOX_HOST_ERR_BUSY -> BufferError`), bulk `NOX_HOST_VALUE_TYPED_ARRAY` fast input path, and `NoxPySharedCtx` factory lifetime in [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h), [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c), [`src/buffer/spec.nox`](src/buffer/spec.nox), [`python/noxpy/ir.py`](python/noxpy/ir.py), and [`python/noxpy/codegen.py`](python/noxpy/codegen.py).
- Added optional NumPy adapter ([`python/noxpy/numpy_adapter.py`](python/noxpy/numpy_adapter.py), [`integrations/numpy/README.md`](integrations/numpy/README.md)) without polluting core `.abi3t.so` dependencies.
- Added [`examples/atlas/`](examples/atlas/) (`ColumnStats`, `neumaier_sum`, `welford_stats`, `moving_average_buf`), [`benchmarks/bench_phase5.py`](benchmarks/bench_phase5.py), [`tests/packaging/test_phase5_buffers_atlas.py`](tests/packaging/test_phase5_buffers_atlas.py), [`ADR-0008`](docs/adr/0008-buffers-numpy-ownership.md), and [`docs/evidence/phase5-2026-11-26.md`](docs/evidence/phase5-2026-11-26.md).

## [0.4.0a1] — 2026-11-26 (Phase 4 Core Alpha: Callbacks, Async/Await & Iterators)

### Added (Phase 4 Core — `noxc v2.2.92` & Host ABI `v3-rc`)
- Synchronized [`native/include/nox_host.h`](native/include/nox_host.h) and [`python/noxpy/_native/include/nox_host.h`](python/noxpy/_native/include/nox_host.h) to `nox-lang v2.2.92` (`NOX_HOST_ABI_VERSION = 3u`, `UR-010` reentrant callback lock + `UR-011` async tasks).
- Added managed `HostObject` / `PyObject` handle runtime (`NoxPyExtRefTable`, generation-checked `NoxHostExternalRef`, `PyGILState_Ensure`/`Release` callback invoke/retain/release) in [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) and [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c), preserving original Python exceptions across `NOX_HOST_ERR_HOST_EXCEPTION` (`nox_host_error_host_token`).
- Implemented native `asyncio.Future` bridge (`_AsyncOp`, `noxpy_async_init_module`, `noxpy_async_op_prepare`, `noxpy_async_on_done`, `noxpy_async_op_finish_start`) with `loop.call_soon_threadsafe` delivery, cooperative cancellation (`nox_host_task_cancel` -> `asyncio.CancelledError`), scheduler deadlock containment (`RuntimeError`), and deferred instance close (`pending_async`/`has_deferred_close`).
- Added iterator protocol (`__iter__` -> `Py_tp_iter`, `__next__` -> `Py_tp_iternext`) with reference-counted `NoxPySharedCtx` sharing and clean `StopIteration` vs domain exception separation (`noxpy_error_is_stop_iteration`), plus updated `abi3t` symbol allowlist in [`python/noxpy/audit.py`](python/noxpy/audit.py).
- Extended Binding IR ([`python/noxpy/ir.py`](python/noxpy/ir.py)) and `.pyi` + C codegen ([`python/noxpy/codegen.py`](python/noxpy/codegen.py)) for `HostObject` (`external_ref` & container `value`), `@export async def` + async plain instance methods, `async def` stubs, and iterator dunders.
- Shipped [`examples/callbacks_async/`](examples/callbacks_async/) (`apply_twice`, `async_add`, `async_with_cb`, `async_slow`, `async_stuck`, `AsyncWorker`, `RangeIter`, `RangeSeq`, `FailingIter`), end-to-end dual-mode tests in [`tests/packaging/test_phase4_callbacks_async.py`](tests/packaging/test_phase4_callbacks_async.py), CI `v2.2.92` toolchain matrix ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)), and [`docs/evidence/phase4-2026-11-26.md`](docs/evidence/phase4-2026-11-26.md).
- Subinterpreter isolation (`Py_mod_multiple_interpreters`) remains conservatively set to `Py_MOD_MULTIPLE_INTERPRETERS_NOT_SUPPORTED` pending `nox-lang v2.2.93` (`UR-013`).
