> **Honest scaling note:** `TYPED_ARRAY` includes one `1.6 MB` host `memcpy` + Nox array allocation per task (`8 × 1.6 MB = 12.8 MB` per batch), so multi-thread scaling saturates around `~2.1–2.4×` on memory bandwidth and `ThreadPoolExecutor` scheduling overhead rather than scaling linearly to `8×`.
