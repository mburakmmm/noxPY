## 2. P0 Memory Safety & Subinterpreter Hardening
- **NumPy `writable_array()` UAF elimination ([`python/noxpy/numpy_adapter.py`](../../python/noxpy/numpy_adapter.py), [`ADR-0008`](../adr/0008-buffers-numpy-ownership.md)):**
  - `writable_array(buf, *, strict=False)` guards exit with `weakref.ref(arr)` and `weakref.ref(mv)`: if `arr` or any derived slice `sub = warr[1:4]` escapes the `with` block, `mv` stays safely pinned (`col.close()` and `resize()` raise `BufferError`/`RuntimeError`, preventing UAF); `strict=True` raises `BufferError` on escape while keeping the pin intact.
  - Added `as_writable_ndarray(buf)` for explicit GC-scoped exclusive mutable views.
- **Subinterpreter `noxpy_interp_attach()` & `atexit` shutdown barrier ([`native/cpython/noxpy_shim.c`](../../native/cpython/noxpy_shim.c)):**
  - Removed `PyGILState_Ensure()` fallback when `owner_interp_id > 0` (returns `0` -> `NOX_HOST_ERR_STATE` instead of attaching to the wrong interpreter).
  - Registered per-interpreter `atexit` hook (`_AsyncOp._shutdown_interp`) setting `interp_alive = 0`, draining `active_attaches` and `active_async_ops` with GIL released, and draining deferred `Py_DECREF`s + retired contexts before `PyInterpreterState` teardown.
