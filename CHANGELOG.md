# Changelog

All notable changes to **NoxPy** are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [PEP 440](https://peps.python.org/pep-0440/).

## [Unreleased]

## [0.4.0a1] — 2026-11-26 (Phase 4 Core Alpha: Callbacks, Async/Await & Iterators)

### Added (Phase 4 Core — `noxc v2.2.92` & Host ABI `v3-rc`)
- Synchronized [`native/include/nox_host.h`](native/include/nox_host.h) and [`python/noxpy/_native/include/nox_host.h`](python/noxpy/_native/include/nox_host.h) to `nox-lang v2.2.92` (`NOX_HOST_ABI_VERSION = 3u`, `UR-010` reentrant callback lock + `UR-011` async tasks).
- Added managed `HostObject` / `PyObject` handle runtime (`NoxPyExtRefTable`, generation-checked `NoxHostExternalRef`, `PyGILState_Ensure`/`Release` callback invoke/retain/release) in [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) and [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c), preserving original Python exceptions across `NOX_HOST_ERR_HOST_EXCEPTION` (`nox_host_error_host_token`).
- Implemented native `asyncio.Future` bridge (`_AsyncOp`, `noxpy_async_init_module`, `noxpy_async_op_prepare`, `noxpy_async_on_done`, `noxpy_async_op_finish_start`) with `loop.call_soon_threadsafe` delivery, cooperative cancellation (`nox_host_task_cancel` -> `asyncio.CancelledError`), scheduler deadlock containment (`RuntimeError`), and deferred instance close (`pending_async`/`has_deferred_close`).
- Added iterator protocol (`__iter__` -> `Py_tp_iter`, `__next__` -> `Py_tp_iternext`) with reference-counted `NoxPySharedCtx` sharing and clean `StopIteration` vs domain exception separation (`noxpy_error_is_stop_iteration`), plus updated `abi3t` symbol allowlist in [`python/noxpy/audit.py`](python/noxpy/audit.py).
- Extended Binding IR ([`python/noxpy/ir.py`](python/noxpy/ir.py)) and `.pyi` + C codegen ([`python/noxpy/codegen.py`](python/noxpy/codegen.py)) for `HostObject` (`external_ref` & container `value`), `@export async def` + async plain instance methods, `async def` stubs, and iterator dunders.
- Shipped [`examples/callbacks_async/`](examples/callbacks_async/) (`apply_twice`, `async_add`, `async_with_cb`, `async_slow`, `async_stuck`, `AsyncWorker`, `RangeIter`, `RangeSeq`, `FailingIter`), end-to-end dual-mode tests in [`tests/packaging/test_phase4_callbacks_async.py`](tests/packaging/test_phase4_callbacks_async.py), CI `v2.2.92` toolchain matrix ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)), and [`docs/evidence/phase4-2026-11-26.md`](docs/evidence/phase4-2026-11-26.md).
- Subinterpreter isolation (`Py_mod_multiple_interpreters`) remains conservatively set to `Py_MOD_MULTIPLE_INTERPRETERS_NOT_SUPPORTED` pending `nox-lang v2.2.93` (`UR-013`).

## [0.3.0a1] — 2026-11-26 (Phase 3 Alpha: Native Classes, Properties, Exceptions & Concurrency)

### Added (Phase 3 — `noxc v2.2.90` & Host ABI `v3-rc`)
- Synchronized [`native/include/nox_host.h`](native/include/nox_host.h) to upstream `NOX_HOST_ABI_VERSION = 3u` (`v2.2.90`, `UR-009` + `UR-010`), adding `nox_host_handle_type_name`, `NOX_HOST_VALUE_HANDLE`, and `NoxHostCallbackOps` declarations.
- Extended [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) and [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) with interpreter-local `abi3t` heap-type handle runtime (`NoxPyObjectData`, `noxpy_obj_init`, `noxpy_obj_new_from_handle`, GC `tp_traverse`/`tp_clear`/`tp_dealloc`, idempotent `close()`/`__enter__`/`__exit__`, GIL-safe `pthread_mutex_lock`), `noxpy_bind_tuple_kwargs`, and custom exception lookup (`noxpy_set_exception_from_host_ex`).
- Extended Binding IR ([`python/noxpy/ir.py`](python/noxpy/ir.py)) and deterministic `.pyi` + C codegen ([`python/noxpy/codegen.py`](python/noxpy/codegen.py)) to automatically emit CPython 3.15 `abi3t` wrapper types for `@export` classes, constructors, instance methods, `@property` getters/setters, `@staticmethod`, `@classmethod`, `__repr__`, `__str__`, `__len__`, top-level/`classmethod` handle factories, and `@export` custom exception subclasses.
- Added runnable Phase 3 example packages [`examples/classes/`](examples/classes/) (`Counter`, `CounterError`, `AffineBox`, `make_counter`) and [`examples/parallel/`](examples/parallel/) (`Worker`, `Accumulator`), verified end-to-end across isolated `CPython 3.15` and unforced `CPython 3.15t` virtualenvs ([`tests/packaging/test_phase3_classes.py`](tests/packaging/test_phase3_classes.py), [`docs/evidence/phase3-2026-11-26.md`](docs/evidence/phase3-2026-11-26.md)).
- Upgraded GitHub Actions CI ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)) to install SHA-256-verified `nox-lang v2.2.90` on Linux & macOS, execute ASan/UBSan shim checks, and gate PRs/pushes on real `noxc` wheels + Phase 1/2/3 dual-mode suites (`NOXPY_REQUIRE_NATIVE=1`).

### Added (Phase 2 — Types, Containers, Defaults, & Packaging Complete on `noxc v2.2.87`)
- Integrated upstream [`native/include/nox_host.h`](native/include/nox_host.h) ABI v2 (`NOX_HOST_ABI_VERSION = 2u`, `NoxHostValue`), backward-compatible with v1 (`experiments/phase0_poc`), resolving [`UR-008`](UPSTREAM_REQUIREMENTS.md) ([`tests/reproducers/ur008_host_abi_containers.sh`](tests/reproducers/ur008_host_abi_containers.sh)).
- Recursive CPython 3.15 `abi3t` `NoxHostValue` converters (`noxpy_py_to_host_value`, `noxpy_host_value_to_py`), `NoxPyParamSpec.has_default`, atomic snapshots (`PySequence_Tuple`, `PyDict_Items`), cycle detection, and nesting depth caps (`NOXPY_MAX_CONV_DEPTH = 32`) in [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) + `_native/` sync, audited cleanly via [`python/noxpy/audit.py`](python/noxpy/audit.py).
- Recursive container/Optional/tuple type validation (`T | None`, `list[T]`, `dict[K, V]`, `tuple[...]`), `marshal`/`return_marshal` verification, and typed constant default values (`int`, `float`, `bool`, `str`, `bytes`, `None`) aligned across [`src/codegen/ir.nox`](src/codegen/ir.nox) and [`python/noxpy/ir.py`](python/noxpy/ir.py).
- Byte-for-byte aligned `.pyi` default formatting and CPython 3.15 `abi3t` value-tree / default C wrappers + PEP 457 `__text_signature__` across [`src/codegen/emit_pyi.nox`](src/codegen/emit_pyi.nox), [`src/codegen/emit_c.nox`](src/codegen/emit_c.nox), and [`python/noxpy/codegen.py`](python/noxpy/codegen.py).
- `nox.lock` validation ([`src/builder/lockfile.nox`](src/builder/lockfile.nox), [`python/noxpy/lockfile.py`](python/noxpy/lockfile.py)), deterministic `.noxpy-cache` (including `ir.py` & native headers in key), reproducible PEP 517 `build_sdist` (`gzip filename=""` + `SOURCE_DATE_EPOCH`), PEP 660 `build_editable`, `noxpy init`, `noxpy clean`, and `noxpy generate-stubs --check`.
- Extended [`examples/mixed_package/`](examples/mixed_package/) and [`tests/packaging/test_phase2_packaging.py`](tests/packaging/test_phase2_packaging.py) (end-to-end `sdist -> wheel` + editable + 8-thread `3.15t` container & concurrent list-mutation stress tests), seeded property/fuzz tests ([`tests/fuzz/`](tests/fuzz/)), [`docs/evidence/phase2-2026-11-25.md`](docs/evidence/phase2-2026-11-25.md), and [`docs/evidence/phase2-2026-11-26.md`](docs/evidence/phase2-2026-11-26.md).
- Security/portability fix in [`python/noxpy/config.py`](python/noxpy/config.py): `_resolve_safe_relpath` now rejects leading backslashes and Windows drive prefixes on POSIX hosts (matching `src/builder/config.nox`).

## [0.1.0a1] — 2026-11-25 (Phase 1 Alpha: Functions & Wheels + Phase 0 Exit)

### Added (Phase 1)
- Positional-only, positional-or-keyword, and keyword-only binding via `noxpy_bind_fastcall_kwargs` (`METH_FASTCALL | METH_KEYWORDS`) in [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) and aligned in [`src/codegen/emit_c.nox`](src/codegen/emit_c.nox) and [`python/noxpy/codegen.py`](python/noxpy/codegen.py).
- Reusable `abi3t` binary auditor ([`python/noxpy/audit.py`](python/noxpy/audit.py)), PEP 517 dual-tag `cp315-abi3.abi3t` wheel builder ([`python/noxpy/build.py`](python/noxpy/build.py)), and CLI commands `noxpy new`, `noxpy build`, `noxpy develop`, and `noxpy check --inspect`.
- Runnable Phase 1 example packages [`examples/hello/`](examples/hello/) and [`examples/fastmath/`](examples/fastmath/) plus clean-venv dual-mode tests ([`tests/packaging/test_phase1_wheels.py`](tests/packaging/test_phase1_wheels.py), [`tests/unit/test_packaging_unit.py`](tests/unit/test_packaging_unit.py)), [`ADR-0004`](docs/adr/0004-binding-ir-and-phase1-wheels.md), and [`docs/evidence/phase1-2026-11-25.md`](docs/evidence/phase1-2026-11-25.md).

### Changed / Verified (Phase 0 Exit)
- Migrated from the temporary `v2.2.70` `--selfhost-obj` bridge to upstream [`native/include/nox_host.h`](native/include/nox_host.h) (`v1`, `--host-abi`, `--emit-obj`, `--emit-shared-lib`), deleting obsolete `nox_v2270_bridge.*` files.
- Upgraded [`native/include/noxpy_abi.h`](native/include/noxpy_abi.h) and [`native/cpython/noxpy_shim.c`](native/cpython/noxpy_shim.c) with bounded per-module `NoxHostContext` pooling (`NOXPY_CTX_POOL_CAP = 64`), `NoxPyHostOps`, `NoxHostBuffer` cleanup converters, and `NoxHostError` inspection.
- Aligned both [`src/codegen/emit_c.nox`](src/codegen/emit_c.nox) and [`python/noxpy/codegen.py`](python/noxpy/codegen.py) to emit `nox_host.h` `v1` wrappers byte-for-byte identically.
- Verified all 7 resolved upstream contracts (`UR-001`–`UR-007`) against `noxc 2.2.81` (`2dcee335`) and verified the same `.abi3t.so` binaries on CPython `3.15.2` and unforced free-threaded `3.15.0b3t` (`gil_enabled=False`, `peak_in_flight=8`), recorded in [`docs/evidence/phase0-2026-11-25-v2.2.81.md`](docs/evidence/phase0-2026-11-25-v2.2.81.md).
